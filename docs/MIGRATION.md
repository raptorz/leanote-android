## 本轮目录管理

- 笔记本菜单可删除已同步的空笔记本。子笔记本、活动笔记、待同步修改和过期版本会阻止删除；通过正常同步接收服务端 tombstone。请求响应丢失后，下次同步可确认结果。

- API2 无原子标签重命名接口，该流程由多个请求组成，不能保证其他设备同时编辑标签时的原子性；跨端并发仍需真实服务端验收。

本轮三项收尾功能及兼容性限制：

- 三项客户端收尾功能已实现。完整历史恢复需要联网、已同步笔记和支持新合同的服务端；旧历史清单未知或文件原件已丢失时明确拒绝完整恢复，保留正文恢复选项。升级前已删除的原件不能凭元数据找回。

以下工作不属于当前功能迁移完成门槛，按用户要求暂缓或留到独立联合目标：

- Android 真机上的 WebView 输入法、选区、系统分享、文件选择、外部应用打开、后台调度和生命周期验收。
- iOS 真机验收；模拟器已覆盖 Debug 启动、图片/文件/多项分享、导入对话框、文件面板、附件外部打开和跨进程显式语言切换。其他来源、超限系统场景、真实相机及长期生命周期归入真机兼容性验证。
- iOS 正式签名、归档和发布流程。
- Android 正式密钥配置、签名产物和 GitHub Release 的实际发布验收。
- 真实 API2 服务器下的弱网、大数据量、跨端并发与长期后台运行验收。弱网、大数据量和
  跨端并发可先在宿主及模拟器自动化完成；系统后台长期唤醒、锁屏、系统回收和厂商限制
  需要真机验收。

## 维护规则

- Flutter 的所有服务端通信必须使用 API2，并与 desktop 的 API 用法保持一致。
- `legacy-android/` 不再修改。
- 功能状态变化先更新根目录 `MIGRATION.md` 的实现记录，再同步更新本文的结论和剩余事项。
- 发布要求分别见 [RELEASE.md](RELEASE.md)、[ANDROID_SHARING.md](ANDROID_SHARING.md) 和 [IOS_SHARING.md](IOS_SHARING.md)。


## 三端历史恢复修复

服务端新增 FilesComplete 和带 USN 的 `/api2/note/restoreHistory`。在线历史菜单增加“恢复正文和附件”，检查本地待同步笔记及未处理附件，恢复成功后正常同步；失败不制造本地附件集合。离线历史仍可恢复正文与编辑器格式，完整集合恢复只在线提供。此前服务端物理删除附件的阻塞已修复，历史上已丢失的文件不在可恢复范围内。服务端、Web 与 desktop 同步修改另见各仓库提交。
